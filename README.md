# Banking-Database-Transaction-Analysis
Thise repository 'Banking Database &amp; Transaction Analysis' Conatains Relational Database Design Between FourTable 
  1.  Customers
  2.  Accounts
  3.  Branches
  4.  Transactions

Where I have Done 
  SELECTED ALL VALUES
  Filtered high-value transactions (amount greater than 20,000).
  Sorted transactions using ORDER BY.
  Calculated total transaction amounts using SUM() and GROUP BY.
  Analyzed total transaction amounts by branch.
  Identified the Top 10 highest-value transactions using TOP and ORDER BY.
  Joined Customers, Accounts, and Transactions tables using INNER JOIN.
  Identified customers with more than 10 transactions using subqueries.
  Analyzed monthly transaction amounts.
  Calculated monthly deposits and withdrawals using CASE WHEN.
